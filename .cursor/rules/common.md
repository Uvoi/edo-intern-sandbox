## Основные принципы
- Всегда отвечай на русском языке
- Отвечай кратко и по существу
- Весь код должен соответствовать стандартам, описанным в `guides/docs/style-guide`

## Архитектура и структура
- Архитектурная документация находится в `guides/docs/arch`. Смотри на неё при взаимодействии с архитектурой
- В репозиториях `ui` и `guides` вносить изменения нельзя
- Игнорируй `.templates` директорию

## UI и стилизация
- В качестве UI библиотеки используется `@astral/ui`, который реэкспортируется через `#shared`
- Использование `sx` запрещено, используй `styled` из `#shared`
- При стилизации для шрифтов, отступов и цветов используй `theme`, определенный в `#shared/ui/theme`
- Перед генерацией кода для React компонентов изучи README.md `@astral/ui` из node_modules или репозиторий `ui`

## Библиотеки и зависимости
- При использовании библиотек, начинающихся на `@astral/*` или `astral/*`, изучай их README.md из node_modules
- Такие библиотеки реэкспортируются через `#shared`
- Для валидации используется `@astral/validations`, пакет реэкспортируется через `#shared` как `v`
- Перед генерацией кода для валидации изучи README.md `@astral/validations` из node_modules

## Документация и типизация
- Для переиспользуемых сущностей реализуй JSDoc
- При изменении переиспользуемых сущностей запускай проверку типов
- Обращай внимание на ошибки линтеров при генерации кода

## Тестирование
- При генерации сложного кода генерируй сразу тесты
- Необходимо следовать стандартам тестирования, которые находятся в `guides/docs/unit-testing`
- Имена тестов должны соответствовать стандарту в `guides/docs/unit-testing/naming.md`
- Тесты не должны следовать антипаттернам, описанным в `guides/docs/unit-testing/antipatterns.md`
